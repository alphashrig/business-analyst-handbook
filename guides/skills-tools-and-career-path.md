## Core skills

| Skill area | Examples | How to build it |
|------------|----------|-----------------|
| **Elicitation and facilitation** | Interviews, workshops, active listening, managing conflict | Shadow seniors; run small sessions; ask for feedback |
| **Analysis and critical thinking** | Root-cause analysis, gap analysis, spotting contradictions | Practise 5 Whys on everyday problems; review others' requirements |
| **Modelling** | BPMN process maps, use cases, data models, state diagrams | Model a process you know (e.g. ordering food online) |
| **Writing** | Clear requirements, user stories, concise emails | Write, cut by half, rewrite |
| **Communication** | Explaining tech to business and business to tech | Present at demos; summarise complex topics in 3 bullets |
| **Domain knowledge** | Insurance, banking, telecom, healthcare, retail... | Read industry news; learn the client's jargon |
| **Technical literacy** | APIs, databases, cloud basics, integration patterns | Online courses; ask developers to explain their work |
| **Data skills** | Excel, basic SQL, dashboards | Query real data to check assumptions |
| **Stakeholder management** | Influence without authority, negotiation | Observe how senior BAs and PMs handle difficult conversations |

## Tools commonly used in ICT companies

| Purpose | Tools |
|---------|-------|
| Backlog and requirements | Jira, Azure DevOps, Trello |
| Documentation | Confluence, SharePoint, Notion, Google Docs |
| Process and diagram modelling | Visio, Lucidchart, draw.io (diagrams.net), Miro, Bizagi |
| Wireframes and prototypes | Figma, Balsamiq, Axure |
| Collaboration and workshops | Miro, MURAL, Teams, Zoom |
| Data | Excel, SQL clients, Power BI, Tableau |
| Testing and UAT | Jira (Xray, Zephyr), TestRail, Azure Test Plans |

Learn concepts first, tools second. Tools change between companies; good analysis transfers everywhere.

## Frameworks and bodies of knowledge

| Name | What it is |
|------|-----------|
| **BABOK® Guide** (IIBA) | The main body of knowledge for business analysis: knowledge areas, tasks, techniques |
| **PMI Guide to Business Analysis** | PMI's BA standard |
| **BCS Business Analysis** | UK-based framework and certifications |
| **Agile Extension to BABOK** | Business analysis in Agile contexts |

## Certifications (roughly by experience)

| Level | Certification |
|-------|---------------|
| Entry | **ECBA** (IIBA), BCS Foundation Certificate in Business Analysis |
| Intermediate (2–3 years) | **CCBA** (IIBA), IIBA-AAC (Agile Analysis) |
| Senior (5+ years) | **CBAP** (IIBA), PMI-PBA, BCS International Diploma |
| Related | CSPO / PSPO (Product Owner), Lean Six Sigma Green Belt, TOGAF (architecture) |

Certifications help, but **real project experience matters more**. Use certifications to structure your learning.

## Career path

```
                                       ┌──▶ Product Owner / Product Manager
                                       │
 Junior / Associate BA ──▶ BA ──▶ Senior BA ──▶ Lead BA / BA Practice Lead ──▶ Head of Business Analysis
                                       │
                                       ├──▶ Business Architect / Enterprise Architect
                                       ├──▶ Project / Programme Manager
                                       ├──▶ Solution Consultant / Pre-sales
                                       └──▶ Domain specialist / Management consultant
```

| Level | Typical experience | What changes |
|-------|-------------------|--------------|
| Junior BA | 0–2 years | Works on features under guidance |
| BA | 2–5 years | Owns requirements for a project or major workstream |
| Senior BA | 5–8 years | Leads complex projects; mentors juniors; involved in pre-sales and discovery |
| Lead BA / Practice Lead | 8+ years | Sets BA standards, methods and templates; manages a BA team |
| Business Architect | 8+ years | Organisation-wide view of capabilities, value streams and strategy |

## Build a portfolio

Even without client documents you can share, you can show your skills:

- Model a public process (e.g. renewing a passport, ordering on a food delivery app) as an as-is/to-be map.
- Write a small BRD or set of user stories for an app idea.
- Write a case study like QuickClaim for a problem you've seen.
- Contribute to this handbook!
